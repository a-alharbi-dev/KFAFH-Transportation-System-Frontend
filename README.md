# KFAFH-Transportation-System-Frontend
 Hospital Transportation Management System

## Overview

This project is a web-based **Hospital Transportation Management System** developed during my training period.

The system was designed to support and organize transportation operations within a hospital environment by providing different interfaces for managing trips, drivers, vehicles, employees, transportation requests, schedules, and related operations.

My role in this project focused on **Front-End Development**, where I worked on designing and improving the user interfaces for different users and system roles.

## My Role

**Front-End Developer**

My responsibilities included:

* Designing and developing the front-end interfaces.
* Creating user-friendly and organized layouts for different system roles.
* Developing interfaces for transportation and trip management.
* Designing pages for driver and vehicle management.
* Developing employee and transportation request interfaces.
* Creating schedule and notification interfaces.
* Improving the overall usability and organization of the system.
* Implementing responsive layouts for different screen sizes.
* Updating the interfaces based on project requirements and feedback.

## System Roles

The system provides different interfaces based on the user's role.

### Admin

The Admin interfaces include:

* Driver Log
* Emergency Requests
* Movement Officer

### Management

The Management interfaces include:

* Driver Management
* Employee Management
* Trip Management
* Vehicle Management
* Reports

### Nurse

The Nurse interfaces include:

* Manage Trips
* My Trips
* Transportation Requests
* Notifications
* Schedule Management

## Development Process

The project was developed with a focus on understanding the transportation workflow and creating interfaces that support the different users involved in hospital transportation operations.

The front-end development process included:

1. Understanding the required transportation workflows.
2. Identifying the needs of different system users.
3. Designing the required interfaces.
4. Developing the front-end pages.
5. Improving the organization and usability of the interfaces.
6. Reviewing and updating the interfaces based on project requirements and feedback.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Objective

The main objective of this project was to provide a more organized and user-friendly interface for managing hospital transportation activities.

The system brings together different transportation operations, including trip management, drivers, vehicles, employees, requests, schedules, and notifications, through interfaces tailored to different user roles.
